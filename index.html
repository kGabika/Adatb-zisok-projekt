Táblákban alkalmazható korlátozások:

PRIMARY KEY(Elsődleges kulcs):

Egyedileg azonosít minden rekordot a táblában. Nem tartalmazhat NULL értéket, és minden értéknek unikálisnak kell lennie.

FOREIGN KEY (Idegen kulcs):

Kapcsolatot teremt két tábla között. Biztosítja, hogy a mező értéke megegyezzen egy másik tábla elsődleges kulcsával.

UNIQUE:

Garantálja, hogy egy oszlopban minden érték különböző legyen (hasonló a Primary Key-hez, de egy táblában több UNIQUE oszlop is lehet).

NOT NULL:

Megakadályozza, hogy az adott oszlop üresen (NULL értékkel) maradjon.

DEFAULT:

Alapértelmezett értéket ad az oszlopnak, ha a rögzítéskor nincs megadva konkrét adat.

CHECK:

Korlátozza az oszlopba kerülő értékek tartományát egy meghatározott feltétel alapján.

Példa:

                CREATE TABLE Felhasznalok (
                    ID INT PRIMARY KEY,                  -- Elsődleges kulcs
                    Felhasznalonev VARCHAR(50) NOT NULL, -- Nem lehet üres
                    Email VARCHAR(100) UNIQUE,           -- Minden email egyedi
                    Eletkor INT CHECK (Eletkor >= 18),   -- Csak 18 év felettiek
                    Regisztracio DATE DEFAULT CURRENT_DATE, -- Alapértelmezett mai dátum
                    CsoportID INT,
                    FOREIGN KEY (CsoportID) REFERENCES Csoportok(ID) -- Idegen kulcs
                );
